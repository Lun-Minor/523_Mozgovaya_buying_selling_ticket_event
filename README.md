
# Информационная система покупки и продажи билетов на мероприятия
## Основные возможности:
* ## Для не зарегистрированного пользователя
1. Каталог мероприятий: Удобный поиск по названию, фильтрация по жанрам и сортировка по рейтингу или алфавиту.
2. Просмотр билетов: выбор конкретной сессии, категории билета и применение льгот.
3. Просмотр карточки мероприятия с основной информацией. 
4. Регистрация с использованием хэша пароля. автоматически после регистрации пользователь получает роль клиента и личный аккаунт
5. Авторизация с использованием хэша паролей и капчей в случаи 3-х неудачных попыток.
 * ### Для администратора
1.  Модерация: страница одобрения заявок на добавление мероприятия в каталог и заявок пользователей на получение статуса «Организатор».
2.  Редактирование существующих мероприятий.
3.  Построение различных  диаграмм  по расходам пользователей в разрезе категорий.
4. Выгрузка статистики в форматированные документы Microsoft Word  и Microsoft Excel.
5. Каталог мероприятий: Удобный поиск по названию, фильтрация по жанрам и сортировка по рейтингу или алфавиту.
6. Покупка билетов: выбор конкретной сессии, категории билета и применение льгот.
7. Личный кабинет: просмотр истории заказов, общей суммы покупок, смена пароля и выход из аккаунта, кнопка для перехода на страницу заявок, кнопка для перехода на страницу диаграмм и отчетов.
8. Избранное: добавление понравившихся мероприятий в список избранного.
9. Отзывы и рейтинги: возможность оставить отзыв и оценку (по 10-балльной шкале), после чего рейтинг мероприятия пересчитывается автоматически.

* ### Для организатора
1. Создание мероприятий:  форма для добавления мероприятия с возможностью указания нескольких сессий (дат/времени) и разных категорий билетов (VIP, Партер, Стандарт) для каждой сессии и заполнением основной информации.
2. Отправка на модерацию: Новые мероприятия попадают в базу со статусом "На модерации" и скрыты от обычных пользователей до одобрения администратором.
3. Каталог мероприятий: Удобный поиск по названию, фильтрация по жанрам и сортировка по рейтингу или алфавиту.
4. Покупка билетов: выбор конкретной сессии, категории билета и применение льгот.
5. Личный кабинет: просмотр истории заказов, общей суммы покупок, смена пароля и выход из аккаунта, создание мероприятия (переход на страницу создания мероприятия).
6. Избранное: добавление понравившихся мероприятий в список избранного.
7. Отзывы и рейтинги: возможность оставить отзыв и оценку (по 10-балльной шкале), после чего рейтинг мероприятия пересчитывается автоматически.

* ### Для клиента
1. Подать заявку на получение роли организатора
2. Каталог мероприятий: Удобный поиск по названию, фильтрация по жанрам и сортировка по рейтингу или алфавиту.
3. Покупка билетов: выбор конкретной сессии, категории билета и применение льгот.
4. Личный кабинет: просмотр истории заказов, общей суммы покупок, смена пароля и выход из аккаунта.
5. Избранное: добавление понравившихся мероприятий в список избранного.
6. Отзывы и рейтинги: возможность оставить отзыв и оценку (по 10-балльной шкале), после чего рейтинг мероприятия пересчитывается автоматически.
